## Current live Pass interaction

One panel shows **FROM**, **TO** and **PASS TYPE** simultaneously. Landscape uses two side-by-side five-column number grids with Hand Pass / Kick Pass underneath. Both active fifteens and both type buttons fit at 1024×768 without dialog scrolling. Player names remain secondary, with complete accessible labels.

FROM and TO can be selected in either order and changed by tapping a different tile in that grid. Selections update in place; there is no stage transition, Next, Back or Save. Both type buttons are disabled until both players have been selected. A valid type tap records exactly one normal Pass and closes immediately. Closing before completion discards the local draft. Reopening Pass starts blank.

The same existing event is passed to the unchanged `recordEvent` callback, adding only its existing `playerNumber`, `receiverNumber`, and `passType` fields. Identity binding, opening time, ID generation, score, storage and chronology are unchanged. The double-record guard remains. Repeated optional passes and a subsequent Goal are normal independent events, without inferred assists, score links, chains or possession objects.

The continuation shortcut, initial-passer option and temporary continuation state have been removed. `src/main.js` is restored exactly to the existing HEAD version; it has no remaining working-tree diff.

## Active players and scouting

Live Pass alone adapts the shared attribution roster using the existing `onFieldKeys` / `playerKey` calculation for either team. It does not introduce another Active XV implementation or change shared selectors. Substituted-off players disappear and substituted-on players appear in both FROM and TO.

Anonymous numbered match participants do not require names or permanent player IDs. With no roster, the shared 1–15 number-only fallback and Other number remain. Clearing an Other-number input clears that draft selection; choosing a tile clears the corresponding Other-number input, so the visible selection and draft stay consistent. No squad/player records are created by this interaction.

Historical Pass editing retains its original broader-roster form.
