## Changes since the previous uncommitted candidate

- Added a maximum of 30 **named selected match-day players** at the team-sheet extraction/review boundary. This is a player count, not a jersey limit. Panel/not-selected rows and permanent Squad storage are not capped. Overflow is excluded from the selection with an explicit evidence notice; it is not silently added or discarded. Confirmation also checks against existing match players, preventing an added 31st selected import row.
- Clean numbered programme rows no longer carry blanket Review required / Name uncertain labels. The existing programme review table shows neutral confidence text for clean rows and amber backgrounds for individually suspicious rows. Summary counts affected rows rather than every separate warning. Duplicate jerseys/names, structural text, unresolved jerseys/names and genuinely weak/clipped readings remain flagged. The name warning uses the same rounded score that is displayed, avoiding a hidden fractional-score warning at displayed 85/100. Jersey acceptance rules were not lowered.
- A missing number alone no longer produces a noisy sequence warning. Readable unnumbered names in an established programme Subs section are preserved as substitutes, with blank jerseys for review. No player is supplied to fill a gap.
- Wrapped substitute prefixes use tighter baseline association to exclude nearby background noise. Bounded rereads include enough vertical margin to retain the top of an observed capital. For such uncertain prefix names only, native image crops can recover a clipped beginning: actual full-word evidence must score at least 85 and the remaining tokens must match the independently observed surname. A recovered prefix remains flagged for name review. No name vocabulary or team-specific mappings were added. No whole-page OCR model or Foireann thresholds changed.
- Removed Alannah Bracken as a special regression expectation. Her programme number was not an importer defect. Generic match-jersey editing/identity protection remains tested.
