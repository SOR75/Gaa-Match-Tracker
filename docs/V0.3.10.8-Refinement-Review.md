# V0.3.10.8-dev — final match-flow refinement

Start: `2f0cca179ce5ad72e0eafb201ccc5b931f772be1`, on
`sideline-v0.3.10`. Three changes only; no Match Flow rule/threshold tuning.

## 1. Persistent sent-off reminder

The existing discipline indicator container now also renders SENT_OFF people
from the authoritative replay. It uses the same responsive grid as temporary
sin bins, with a red state and the team/current field count. There is no timer,
return control or required action. Multiple sanctions share the existing layout.
The reminder follows edit/delete/Undo/replay and persists during the untimed
shootout too; temporary countdown/return controls remain hidden in that phase.
It does not change Active XV, sanction, return or LGFA ET replacement rules.
An LGFA dismissed original can remain SENT_OFF while a lawful ET replacement
makes the team count 15; the banner reports that actual count.

## 2. Normal-Time Analysis before Extra Time

Ending H2 level completes the existing H2 clock, persists the existing INTERVAL
phase, and opens Normal-Time Analysis before the Draw / Start ET decision.
The screen reuses the full-time dashboard, KPI, shot/pitch, contributor, Match
Flow, evidence and keeper components. Start Extra Time calls the existing period
transition and returns to ET1's existing preparation/discipline choices. Finish
as Draw calls the existing match completion flow.

`normalTimeMatch` is a pure temporal projection: H1/H2 events and normal-time
clock records only, paused at the recorded normal-time boundary. ET events,
ET clock records, shootout data and penalty-result metadata cannot enter it.
There is no second statistics database or stored score snapshot. Explicit later
corrections to H1/H2 can still recalculate this view; “frozen” means the period
boundary, not permanent suppression of factual corrections. Unknown legacy
period durations remain unknown.

The view can be revisited after ET via final analysis and read-only History.
Reload and native History Resume restore the pending decision from existing
clock state. A match that already has an ET frontier/event cannot reopen that
normal-time decision. Half-Time Analysis is unchanged. Final Full-Time Analysis
still includes the complete football match and separate penalty result.
Timeline CSV still exports the current/selected match's full canonical Timeline,
including when its download button is reached from normal-time analysis.

## 3. End-of-ET shootout eligibility

A read-only eligibility adapter consumes the canonical field/discipline replay
at the measured end-of-ET boundary. Known participants are resolved by match/
permanent identity, not by assuming a jersey indicates eligibility.

- LGFA takers must be eligible end-of-ET participants. A dismissed original #8
  stays ineligible after lawful ET replacement #18; the active replacement can
  take a penalty. Off-field unused substitutes/panel members cannot bypass the
  rule by remaining on the saved roster.
- GAA ordered-off people remain ineligible. A Black-card temporary dismissal
  that is fully expired at ET end can permit shootout selection even without an
  actual football return. This does not add an Active XV player, return event,
  playing minutes or substitution, and does not import LGFA ET exemptions.
- The user explicitly confirmed the GAA eligible-bench-goalkeeper exception is
  a Change GK exception only. It does not grant that bench player kicker or
  general football eligibility. Sent-off people and unexpired sin bins cannot
  use it. Unselected panel members do not acquire match-day eligibility.

The actual live picker, Other Number input, changed historical participant
selection, keeper change and new-penalty save path all apply the checks.
An invalid manual kicker entry clears a prior tentative kicker so the old
selection cannot be silently recorded instead. A restored ineligible keeper
cannot receive new penalty credit until an eligible keeper is explicitly chosen.

The pure shootout-ledger math functions retain their context-free compatibility
signatures; live UI calls pass the match context to enforce football eligibility.
Existing recorded attempts remain readable and are not automatically rewritten.
An outcome-only historical correction can preserve the original recorded actor;
changing that actor is checked. First five, early completion, paired sudden death,
Undo, separate kicker/keeper metrics and persistence remain the existing engine.

## Compatibility and remaining uncertainty

Default numbered match identities use the replay's Active XV. Truly anonymous/
legacy matches without a reliable lineup keep the existing unknown-lineup
fallback, constrained by known off/on facts; they do not acquire permanent IDs.
No lineup, playing time, identity or missing event is invented. Where measured
period timing is missing, the GAA expiry exception cannot be assumed.

The GAA bench-GK question was resolved explicitly by the user; no additional
referee/injury-permission workflow was introduced. Physical iPad acceptance of
these changes remains the next stage after review and a separately authorised push.

Version identifiers consistently read `V0.3.10.8-dev`. No storage/schema or PWA
migration, historical match correction, CSV redesign or analysis tuning is included.
